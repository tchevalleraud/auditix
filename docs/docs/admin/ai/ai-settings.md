# AI settings (admin) <AIBadge />

Global toggles that apply to every assistant.

| Setting                    | Default | Description                                                 |
|----------------------------|---------|-------------------------------------------------------------|
| AI features enabled        | `true`  | Master kill-switch. When off, the AI side panel is hidden.  |
| Tool use opt-in            | `false` | Disables tool use globally even on assistants where it's on.|
| Prompt + completion logging | `false` | Persist full conversations for offline review.              |
| Max tokens per response    | `2048`  | Hard cap to control spend.                                  |
